🚀 SolScan Mobile — Solana Wallet Explorer & Swap UI

A mobile crypto app built with React Native (Expo) that lets you explore any Solana wallet address — check balances, tokens, recent transactions, and try a swap interface inspired by real wallet apps like Phantom.

This project was mainly built to understand how mobile Web3 apps work under the hood and how crypto wallets fetch on-chain data.

✨ What it can do
🔍 Wallet Explorer

Search any Solana wallet address

See SOL balance instantly (Mainnet)

View all SPL tokens in the wallet

Check recent transactions

Open transactions directly on Solscan

💱 Swap Interface (UI only)

Clean token swap screen

Token selector style UI

Enter amount to swap

Swap direction button

Designed so real swap APIs (Jupiter, Raydium) can be plugged in later

📱 Mobile Experience

Built with Expo for quick mobile development

Dark theme inspired by modern crypto apps

Smooth UI designed for phones

🛠 Tech Used

React Native (Expo)

TypeScript

React Navigation

Solana JSON-RPC API

Ionicons
